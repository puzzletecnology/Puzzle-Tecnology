# 🧩 PuzzleOS | The Modular Operating System

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-1.0.0--alpha-orange)

**PuzzleOS** es un sistema operativo adaptativo diseñado para el hardware modular de **Puzzle Technology**. Nuestra misión es terminar con la obsolescencia programada permitiendo que el software y el hardware evolucionen pieza a pieza.

## 🚀 La Visión
A diferencia de los sistemas cerrados, PuzzleOS utiliza una arquitectura de **detección dinámica de módulos**. Cuando cambias una cámara o un sensor físico, el Kernel reconfigura los drivers en tiempo real sin necesidad de reiniciar.

### Características Principales
- **Hot-Swap Ready:** Reconocimiento instantáneo de hardware magnético.
- **Eco-Friendly:** Diseñado para extender la vida útil de los componentes.
- **Open Source:** Hardware y software documentado para que cualquiera pueda crear sus propios módulos.

## 🛠 Estructura del Proyecto
- `/kernel`: Núcleo del sistema y gestión de interrupciones.
- `/drivers`: Biblioteca de controladores para módulos estándar (Cámaras, GPS, Pantallas).
- `/web-sim`: El simulador interactivo que ves en nuestra landing page.
